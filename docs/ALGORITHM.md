# RotaryDialUnified - Telephone Dialer Decoding Algorithm

## Overview

The **RotaryDialUnified** library decodes the pulses generated by a **mechanical telephone dial** (rotary dial) connected to an Arduino digital pin. It uses **interrupts** to detect the edges of the electrical signals generated by the dialer mechanism.

---

## Principle of Operation of the Telephone Dialer

### How Does a Rotary Dial Work?

A mechanical telephone dialer has:

1. **Disk numbered from 1 to 9 and 0** (10 positions)
2. **Spring mechanism** that returns the disc to the initial position
3. **Electrical contacts** that open and close during return
4. **Gear wheel** that generates pulses

### Pulse Generation

When the user spins the disk and releases it:

| Dialed digit | Generated Pulses | Explanation |
|----------------|----------------|------------|
| 1 | 1 pulse | 1 opening/closing of contacts |
| 2 | 2 pulses | 2 openings/closings |
| 3 | 3 pulses | 3 openings/closings |
| ... | ... | ... |
| 9 | 9 pulses | 9 openings/closings |
| 0 | 10 pulses | 10 openings/closings (treated as 0) |

**Electrical standard:**

```
Digit "3" dialed:

Signal:  HIGH ┐    ┌─┐    ┌─┐    ┌─┐         ┌───────────┐
              └─15─┘ └─15─┘ └─15─┘ └─15──────┘           
              ms   ms   ms   ms          600ms
                                           ▲
                                     End of digit

Total: 3 pulses detected → returns digit 3
```

## Library Algorithm

### Timing constants

```cpp
#define MS_DEBOUNCE    15   // Minimum 15ms HIGH to count as a valid pulse
#define MS_DIGITEND   600   // 600ms without a pulse = end of the digit
```

### State variables

```cpp
static int interruptPin;        // Configured interrupt pin
static int last;                // Last state read (HIGH/LOW)
static unsigned long lastHigh;  // Timestamp of the last rising edge
static int pulseCount;          // Accumulated pulse counter
```

### Algorithm Flow

```
┌─────────────────────────────────────────────────────────────┐
│                         SETUP                               │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│ 1. Configures the pin as INPUT_PULLUP                       │
│ 2. Registers the CHANGE interrupt (any change)              │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
                    ┌─────────────────┐
                    │    INTERRUPT    │
                    │    change()     │
                    └────────┬────────┘
                             │
              ┌──────────────┼──────────────┐
              ▼              ▼              ▼
        ┌─────────┐   ┌──────────┐   ┌──────────┐
        │ Debounce│   │  Pulse   │   │  End of  │
        │ (15ms)  │   │   count  │   │  digit   │
        │         │   │          │   │          │
        └────┬────┘   └────┬─────┘   └────┬─────┘
             │             │              │
             ▼             ▼              ▼
┌─────────────────────────────────────────────────────────────┐
│                         LOOP                                │
│  available() returns TRUE when:                             │
│  - pulseCount > 0  AND                                      │
│  - millis() - lastHigh > MS_DIGITEND (600ms)                │
└─────────────────────────────────────────────────────────────┘
```

### Interrupt Function: `change()`

This is the critical function called on every state change of the pin:

```cpp
void RotaryDialUnified::change() {
    // STEP 1: Ignore if the state did not change (hardware debounce)
    int state = digitalRead(interruptPin);
    if(state == last) return;
    last = state;

    // STEP 2: Ignore if a digit is already pending (do not read while dialing)
    if(available()) return;

    // STEP 3: Handle the edge
    if(state) {
        // RISING EDGE
        // Record the timestamp - start of the HIGH pulse
        lastHigh = millis();
    } else {
        // FALLING EDGE
        // Measure how long HIGH lasted
        unsigned long highLen = millis() - lastHigh;
        
        // STEP 4: Check whether the pulse is valid (debounce > 15ms)
        if(highLen > MS_DEBOUNCE) {
            pulseCount++;  // Valid pulse!
        }
    }
}
```

### Full Digit Detection: `available()`

```cpp
int RotaryDialUnified::available() {
    // Returns TRUE when:
    // 1. At least 1 pulse has been counted (pulseCount > 0)
    // 2. More than 600ms have passed since the last pulse (dialing finished)
    return (pulseCount > 0 && millis() - lastHigh > MS_DIGITEND);
}
```

### Digit reading: `read()` and `readPulses()`

```cpp
int RotaryDialUnified::readPulses() {
    if(available()) {
        int ret = pulseCount;   // Save the count
        pulseCount = 0;          // Reset for the next digit
        return ret;             // Return the raw pulses
    }
    return -1;                  // Nothing available
}

int RotaryDialUnified::read() {
    int ret = readPulses();
    if(ret == 10) return 0;     // 10 pulses = digit 0
    return ret;                  // 1-9 pulses = digits 1-9
}
```

## Implemented Protections

### 1. Debounce (MS_DEBOUNCE = 15ms)

```
Problem: mechanical contacts "bounce" when they close

Real signal:   HIGH ──┐  ┌─┐ ┌─┐    ┌──────────┐
                      └──┘ └─┘ └───┘          └───
                      ▲
                      bouncing (~5ms)
                      
With debounce: HIGH ──┐                     ┌────
                      └─────────────────────┘
                      
                      └── counts only if HIGH > 15ms
```

### 2. Detection of Digit End (MS_DIGITEND = 600ms)

The rotary dial mechanism takes ~600ms to return completely after the last pulse. This timeout ensures that:
- Does not read the digit before all pulses are sent
- Allows continuous dialing without losing digits
- Separate consecutive digits

### 3. Prevention of Reading During Dialing

```cpp
if(available()) return;  // In the interrupt
```

It prevents new pulses from being counted while a digit has not been read by the main program.

## Use of the Library

### Basic Example

```cpp
#include <RotaryDialUnified.h>

#define ROTARY_DIAL_PULSE_PIN 2  // Must support interrupts

void setup() {
    Serial.begin(9600);
    RotaryDialUnified::setup(ROTARY_DIAL_PULSE_PIN);
}

void loop() {
    // Check whether a digit is ready
    if(RotaryDialUnified::available()) {
        int digit = RotaryDialUnified::read();  // 0-9
        Serial.println(digit);
    }
}
```

### API Available

| Function | Return | Description |
|--------|---------|-----------|
| `setup(pin)` | void | Configure interrupt pin |
| `available()` | bool | TRUE if a complete digit is detected |
| `read()` | int | Returns digit (0-9) or -1 |
| `readPulses()` | int | Returns the raw pulse count (1-10) or -1 |

## Hardware requirements

### Dialer Connection

```
Telephone dial
        │
        ├── Terminal 1 ────┬──[10K Resistor]── VCC (5V)
        │                  │
        │                  └── Arduino pin (e.g. D2)
        │
        └── Terminal 2 ──── GND

Note: the pin must support external interrupts:
     - Arduino Nano/Uno: D2 or D3
     - Arduino Mega: D2, D3, D18, D19, D20, D21
     - PropMaker RP2040: any digital pin
```

### Expected Electrical Signal

```
Pin at rest:         HIGH (INPUT_PULLUP)

While dialing:       pulses LOW/HIGH as the contacts open/close
                     (LOW level when the contact closes)

Dialing complete:    returns to HIGH
```

## Configurable Constants

| Constant | Default Value | Description |
|-----------|--------------|-----------|
| `MS_DEBOUNCE` | 15ms | Minimum HIGH duration to consider a valid pulse |
| `MS_DIGITEND` | 600ms | Time without pulse to consider full digit |

**To adjust:**

```cpp
// In your code, before #include <RotaryDialUnified.h>
#undef MS_DEBOUNCE
#define MS_DEBOUNCE 20  // More conservative

#undef MS_DIGITEND
#define MS_DIGITEND 800 // Slower dials

#include <RotaryDialUnified.h>
```

## Limitations and Considerations

1. **Interrupt Pin:** Must use a pin that supports `attachInterrupt()` on the specific board

2. **Non-blocking:** The library uses interrupts, it does not block `loop()`

3. **Single digit:** Does not store multiple digits - read before the next one!

4. **Fixed timing:** Very fast or slow dialers may require adjustment of the constants

5. **Excessive bounce:** Very worn contacts can cause incorrect readings
